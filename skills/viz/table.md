# Table Design

## When to use
Detail view or when >8 categories make charts unreadable.

## Configuration
- Show all columns from cleaned data.
- Alternating row colors: white / #F3F2F1.
- Header: bold, #252423.
- Max 20 rows visible, enable scroll.

## model_spec fields
```json
{"type": "tableEx", "columns": ["<col1>", "<col2>"]}
```
